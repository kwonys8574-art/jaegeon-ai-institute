재건교회 AI 학술연구소 - 사용 설명서
=====================================

[1] 사이트 열어보기
- jaegeon-ai-institute 폴더 안의 index.html 파일을 더블클릭하면
  크롬(또는 기본 브라우저)에서 바로 열립니다. (서버 설치 필요 없음)
- 상단에서 "원어연구 / 성경 각 권 연구 / 주석 및 성경지리 / 독서토론"
  카테고리로 이동할 수 있고, 각 카드의 "챗봇 열기" 버튼을 누르면
  해당 ChatGPT 챗봇이 새 탭에서 열립니다.

[2] 관리자 페이지로 챗봇 등록/수정/삭제하기
- admin.html 파일을 더블클릭해서 엽니다.
- 처음 만든 비밀번호: jaegeon2026
  (비밀번호를 바꾸고 싶으면 admin.js 파일을 텍스트 편집기로 열어서
   맨 위 ADMIN_PASSWORD = "jaegeon2026" 부분의 큰따옴표 안 글자만 바꾸세요.)
- 로그인 후 "+ 새 챗봇 추가" 버튼으로 카테고리/제목/설명/링크를 입력해
  등록할 수 있고, 각 항목의 "수정"/"삭제" 버튼으로 관리할 수 있습니다.

[3] 변경사항을 실제로 사이트에 반영하기 (중요)
- 관리자 페이지에서 추가/수정/삭제한 내용은 "지금 사용 중인 브라우저"에만
  우선 저장됩니다 (index.html을 새로고침하면 바로 확인 가능).
- 다른 사람들도(예: 다른 컴퓨터, 다른 브라우저에서) 같은 목록을 보게 하려면:
  1. 관리자 페이지 위쪽의 "data.js 파일로 저장" 버튼을 클릭
  2. 다운로드된 data.js 파일을 jaegeon-ai-institute 폴더 안의
     기존 data.js 파일에 덮어쓰기(교체)
  3. 이렇게 교체된 폴더를 그대로 인터넷에 올리면(배포하면) 모두가
     같은 목록을 보게 됩니다.

[4] 나중에 실제 인터넷 주소로 배포하고 싶을 때
- 이 폴더(jaegeon-ai-institute) 전체를 그대로 사용하면 됩니다.
- Netlify, Vercel, GitHub Pages 같은 무료 정적 사이트 호스팅에
  폴더째로 올리면 별도 설치 없이 바로 인터넷에 공개됩니다.
- 배포를 도와드릴 수도 있으니 필요하면 말씀해 주세요.

[5] 참고 / 한계
- 이 관리자 비밀번호는 "완전한 보안"이 아니라 개인/소규모 관리용 정도의
  간단한 잠금입니다. 여러 관리자가 각자 로그인하거나 더 강한 보안이
  필요하면 서버 기반으로 다시 만들어야 하며, 이 경우 말씀해 주시면
  별도로 도와드릴 수 있습니다.
